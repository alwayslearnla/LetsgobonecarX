Vamos ligar o painel

Isso é feito uma única vez neste celular. Depois é só abrir o painel e cadastrar.

  1. No GitHub (conta alwayslearnla), abra github.com/settings/personal-access-tokens/new.
  2. Em Token name escreva Painel Bonecar. Em Expiration, escolha No expiration (sem validade).
  3. Em Repository access, marque Only select repositories e escolha LetsgobonecarX.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Toque em Generate token, copie a chave (começa com github_pat_) e cole abaixo.

A chave fica guardada só neste aparelho e só dá acesso ao site da loja.
